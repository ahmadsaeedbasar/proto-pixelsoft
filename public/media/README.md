Place a Lottie JSON file here named `hero.json` for the local hero animation.

Recommended steps:
1. Visit https://lottiefiles.com and find a professional hero/device/mockup animation.
2. Download the JSON file and save it to `public/media/hero.json`.
3. Start the dev server: `npm run dev` and the hero will load from `/media/hero.json`.

If you prefer, you can instead set a remote Lottie URL in `src/app/pages/Landing.tsx`.
